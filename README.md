# Rentab'Pass – version web

Suivi de la rentabilité d'un abonnement cinéma (CinéPass -26, Classique, Silver, Gold, option Duo), mois par mois et sur l'année.

Site : https://stephaneee.github.io/Rentabpass_Web/

- Les données restent dans le navigateur (exportez une sauvegarde de temps en temps depuis Réglages).
- La base de films utilise l'API TMDB avec votre propre clé, saisie dans Réglages et gardée dans le navigateur.
- Installable : dans Chrome, menu ⋮ › « Ajouter à l'écran d'accueil ».

Ce produit utilise l'API TMDB sans être approuvé ni certifié par TMDB. Application personnelle, sans lien avec l'exploitant des cinémas. Copyright : Stanji.
